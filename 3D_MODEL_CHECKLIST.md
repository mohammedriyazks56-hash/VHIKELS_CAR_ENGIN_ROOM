# 3D asset requirements

- Use GLB/glTF format.
- Obtain a model you created or have a license to distribute in an app.
- Use separate named meshes for every part users should select or hide.
- Suggested engine meshes: Engine_Block, Cylinder_Head, Piston_1..4, Connecting_Rods, Crankshaft, Camshafts, Turbocharger, Oil_Pan.
- Suggested transmission meshes: Transmission_Housing, Torque_Converter, Gear_Set, Input_Shaft, Output_Shaft, Valve_Body.
- Suggested 4WD meshes: Transfer_Case, Front_Output, Rear_Output.
- Set correct scale, orientation, pivot and materials.
- Optimize geometry and textures for mobile devices.
- Verify that the model matches the exact vehicle/year/market.
